# AI-Based Student Performance Prediction System

## Live Demo

- Streamlit app: https://student-performance-prediction-qbjvdcjrgthfs3uzwfgwgi.streamlit.app/
- GitHub repository: https://github.com/wpdevgenius-cloud/student-performance-prediction

## Overview
This Applied AI internship project estimates a student’s final Mathematics grade (`G3`, 0–20) from academic, demographic, social, and behavioural information. It includes a reproducible scikit-learn pipeline, model comparison, explainability charts, tests, a Streamlit application, and presentation materials.

## Problem Statement
Student performance is influenced by multiple factors. A transparent prediction prototype can help start an academic-support conversation by combining patterns from historical data. It does not replace educators or make definitive decisions.

## Dataset
The project downloads the official [UCI Student Performance dataset](https://archive.ics.uci.edu/dataset/320/student+performance) and stores the Mathematics subset at `data/student-mat.csv`. The Mathematics subset contains **395 rows** and 33 columns (the wider Portuguese subset has 649 rows). Target: `G3`, the final grade from 0 to 20.

## Features
The main model uses all 32 non-target fields, including student background, family and school support, study habits, absences, and prior grades `G1` and `G2`.

### Leakage / deployment timing
`G1` and `G2` are earlier-period grades, so they are valid inputs only when the predictor runs after those grades are available. The training script also trains a comparison scenario without `G1`/`G2`; results are saved in `reports/grade_feature_comparison.json`. That scenario is harder but more suitable for early-stage support planning.

## Technology Stack
Python, Pandas, NumPy, scikit-learn, Streamlit, Matplotlib, Seaborn, Joblib, Pytest, and python-pptx.

## Machine Learning Approach
A leakage-safe `ColumnTransformer` imputes and scales numeric features and one-hot encodes categorical features inside each pipeline. Using `random_state=42`, the project makes an 80/20 holdout split and compares Linear Regression, Random Forest, Gradient Boosting, and Extra Trees using MAE, RMSE, and R². The best holdout-RMSE model is persisted as a complete preprocessing-plus-model pipeline.

## Evaluation Metrics
Actual fixed-holdout results generated by this project run:

| Model | MAE | RMSE | R² |
| --- | ---: | ---: | ---: |
| Gradient Boosting | 1.128 | 1.922 | 0.820 |
| Random Forest | 1.215 | 2.026 | 0.800 |
| Extra Trees | 1.390 | 2.298 | 0.743 |
| Linear Regression | 1.647 | 2.378 | 0.724 |

Gradient Boosting was selected by lowest RMSE. `reports/model_comparison.csv` is regenerated by `python src/train_model.py`; rerunning training may reproduce these values with the fixed seed.

## Limitations and Future Improvements
The data is small, historic, and limited to Portuguese secondary schools. Results may not generalize to other schools or contexts. Future work could use larger representative datasets, fairness analysis, calibration/uncertainty intervals, and educator feedback.

## Disclaimer
This system is an educational machine-learning prototype intended to demonstrate predictive analytics. Predictions should not be treated as definitive judgments about a student’s ability or future.
